    Setup checklist
    
    
      
  1. Host this file over HTTPS on a domain you control (for GitHub Pages: put it at the root of a repository and turn on Pages under Settings).
    2. 
      
  2. If the Apple developer portal asks you to verify the domain, download apple-developer-domain-association.txt and serve it at https://your-domain/.well-known/apple-developer-domain-association.txt. On GitHub Pages this needs an empty .nojekyll file in the repository root, and the file must sit at the root of the domain (a username.github.io repository or a custom domain).
    3. 
      
  3. Open your Services ID, choose Sign in with Apple, then Configure. Select the primary App ID, add the domain above, and add the Redirect URI above as a Return URL, exactly as shown.
    4. 
      
  4. Enter the Services ID, sign in, and use the code within about five minutes. It works only once.
    5. 
      
  5. On your backend, call the client with client_platform="web", and make sure its web redirect URI is exactly the Redirect URI above.
